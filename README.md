Időpontfoglaló rendszer alapjai.
PHP 8.2 verzión alapuló Yii2 keretrendszer Basic appjében megvalósított CalendarJS modult használó időpontfoglaló rendszer, melyet elsősorban kis- és középvállalkozások használatára szánható.
A rendszer felépítése és struktúráltsága, valamint az adatbázis kapcsolat a modelleken belül lehetővé teszi hogy egyszerű tárgyalásra vagy találkozóra szánt időpontfoglalás mellett akár árazást és szolgáltatásokat is hozzáadjunk a kódhoz.
